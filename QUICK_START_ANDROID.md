# 🚀 Быстрый старт - Android приложение

Пошаговая инструкция для запуска CS:GO Trading Bot на Android за 10 минут.

## ⚡ Шаг 1: Запустите Backend Server (2 минуты)

### 1.1 Установите зависимости:

```bash
pip install fastapi uvicorn
```

### 1.2 Запустите API server:

```bash
cd /home/user/Csgobot
python api_server.py
```

Вы должны увидеть:
```
🚀 Starting CS:GO Trading Bot API Server
✅ Bot components initialized successfully
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 1.3 Проверьте работу (в новом терминале):

```bash
curl http://localhost:8000/health
```

Если видите `"status": "healthy"` - отлично, переходим дальше!

---

## 📱 Шаг 2: Настройте Android приложение (3 минуты)

### 2.1 Узнайте IP адрес компьютера:

**Linux/Mac:**
```bash
ip addr show | grep inet
# или
ifconfig | grep inet
```

**Windows:**
```bash
ipconfig
```

Найдите локальный IP (обычно начинается с `192.168.x.x` или `10.0.x.x`)

### 2.2 Откройте проект в Android Studio:

```
File > Open > выберите папку android_app/
```

### 2.3 Настройте URL сервера:

Откройте `app/build.gradle` и измените строку:

```gradle
buildConfigField "String", "API_BASE_URL", "\"http://ВАШ_IP:8000\""
```

**Примеры:**
- Эмулятор: `http://10.0.2.2:8000`
- Реальное устройство: `http://192.168.1.100:8000` (ваш LAN IP)

### 2.4 Синхронизируйте проект:

```
File > Sync Project with Gradle Files
```

---

## 🎯 Шаг 3: Запустите приложение (2 минуты)

### 3.1 Подключите устройство или запустите эмулятор:

**Опция A: Реальное Android устройство**
1. Включите "Режим разработчика" на устройстве
2. Включите "Отладка по USB"
3. Подключите к компьютеру через USB

**Опция B: Эмулятор**
1. `Tools > Device Manager`
2. Create Virtual Device (Pixel 6, API 34)
3. Launch

### 3.2 Запустите:

Нажмите зеленую кнопку **Run** (▶️) или `Shift + F10`

### 3.3 Подождите установки:

Gradle скомпилирует и установит приложение (~1-2 минуты при первом запуске)

### В приложении вы должны увидеть:

✅ **Статистику** в верхней карточке:
```
📊 Statistics
Total Items: 50
Items with Data: 45
...
```

✅ **Торговые возможности** в списке ниже:

## 🐛 Если что-то пошло не так

### Проблема: "Connection refused"

```bash
# 1. Проверьте что сервер запущен:
curl http://localhost:8000/health

# 2. Проверьте firewall (Linux):
sudo ufw allow 8000

# 3. Для эмулятора используйте:
API_BASE_URL = "http://10.0.2.2:8000"
```

### Проблема: "No opportunities found"

```bash
# Соберите данные:
python bot.py collect

# Проверьте что есть предметы в config.yaml:
cat config.yaml | grep -A 20 items:
```

### Проблема: App crashes

```bash
# Проверьте логи в Android Studio:
View > Tool Windows > Logcat

# Фильтр: "com.csgobot.trading"
```
