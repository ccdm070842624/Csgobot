## ⚙️ Конфигурация

### Основные настройки

**config.yaml**:
```yaml
# API ключ CSGOFloat (получите на csgofloat.com)
api:
  csgofloat:
    api_key: "your_api_key_here"

# Отслеживаемые предметы
items:
  - "AK-47 | Redline (Field-Tested)"
  - "AWP | Asiimov (Field-Tested)"

# Торговая стратегия
strategy:
  min_buy_confidence: 50
  trend_days: 7
  prediction_days_ahead: 7
  volatility_threshold: 15.0

# Бэктестинг
backtesting:
  initial_balance: 100.0
  transaction_fee: 0.05  # 5%

# Уведомления
notifications:
  console:
    enabled: true
    min_confidence: 60

  email:
    enabled: false  # Включите для email уведомлений
```

### CLI Аргументы

```bash
# Полная справка
python bot.py --help

# Использовать кастомный конфиг
python bot.py --config my_config.yaml --full

# Анализ конкретных предметов
python bot.py --analyze --items "AK-47 | Redline (Field-Tested)"

# Задать уровень логирования
python bot.py --full --log-level DEBUG

# Бэктест на 90 дней
python bot.py --backtest --days 90
```

## 📈 Алгоритмы

### 1. Анализ трендов
- **Линейная регрессия** для определения направления тренда
- Расчет силы тренда (процент изменения)
- Классификация: UP/DOWN

### 2. Прогнозирование цен
- **Random Forest Regressor** (100 деревьев)
- Признаки: дни назад, цена
- Кросс-валидация для точности

### 3. Оценка волатильности
- Стандартное отклонение цен
- Нормализация на среднюю цену
- Пороговые значения для рисков

### 4. Скоринг рекомендаций
```
Score = (Trend * 30) + (Prediction * 40) + (Volatility * 20) + (Volume * 10)

BUY:  Score > 30
SELL: Score < -30
HOLD: -30 ≤ Score ≤ 30
```

## 📊 Производительность

### Системные требования
- **RAM**: 512 MB минимум
- **CPU**: 1 ядро (2+ рекомендуется)
- **Disk**: 100 MB для БД и отчетов
- **Network**: Стабильное соединение

### Скорость работы
- **Сбор данных**: ~5-10 сек на предмет
- **Анализ**: ~1-2 сек на предмет
- **Бэктестинг**: ~10-30 сек
- **Генерация графиков**: ~2-3 сек на график

### Оптимизация
```yaml
# config.yaml
advanced:
  ml:
    n_estimators: 50  # Меньше → быстрее, но менее точно
    max_depth: 10     # Меньше → быстрее

api:
  csgofloat:
    rate_limit_delay: 3  # Меньше → быстрее, но риск rate limit
```

## 🐛 Известные ограничения

1. **API Rate Limits**
   - CSGOFloat без ключа: ~10 запросов/мин
   - С ключом: ~100 запросов/мин
   - Решение: Увеличьте `rate_limit_delay`

2. **Точность прогнозов**
   - Зависит от количества данных
   - Минимум 50 точек для хорошей точности
   - Решение: Собирайте данные регулярно

3. **Задержка данных**
   - Данные обновляются с задержкой
   - Рынок может измениться быстро
   - Решение: Проверяйте цены вручную

4. **Matplotlib в CLI**
   - `plt.show()` не работает в headless
   - Решение: Графики сохраняются автоматически
