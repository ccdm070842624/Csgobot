## Основные возможности

### 1. Сбор данных
- Парсинг CSGOFloat API
- Сохранение истории цен
- Расчет статистики рынка

### 2. Анализ трендов
- Линейная регрессия
- Расчет направления и силы тренда
- Анализ волатильности

### 3. Прогнозирование
- Random Forest для предсказания цен
- Оценка уверенности прогноза
- Расчет потенциальной прибыли

### 4. Торговые рекомендации
- **BUY** - Покупать (восходящий тренд + позитивный прогноз)
- **SELL** - Продавать (нисходящий тренд + негативный прогноз)
- **HOLD** - Держать (неопределенная ситуация)
- **WAIT** - Ждать (недостаточно данных)

### 5. Визуализация
- Графики истории цен
- Линии трендов
- Диапазоны цен

## Параметры настройки

### В функции `collect_market_data()`:
- `items_to_track` - список отслеживаемых предметов
- `limit` - количество предложений на запрос (по умолчанию 20)
- Задержки между запросами (по умолчанию 5 сек)

### В классе `PriceAnalyzer`:
- `days` - период анализа истории (7-30 дней)
- `days_ahead` - горизонт прогноза (по умолчанию 7 дней)
- Пороги для рекомендаций (score > 30 для BUY)

## Известные ограничения

1. **Rate Limits**: CSGOFloat ограничивает количество запросов
   - Без API ключа: ~10 запросов/минуту
   - С API ключом: ~100 запросов/минуту

2. **Точность прогнозов**: Зависит от объема данных
   - LOW: < 50 точек данных
   - MEDIUM: 50-200 точек
   - HIGH: > 200 точек

3. **Задержка данных**: Рыночные данные обновляются с задержкой

## Рекомендации

1. **Запускайте регулярно**: Собирайте данные несколько раз в день для точности
2. **Используйте API ключ**: Получите на csgofloat.com для увеличения лимитов
3. **Проверяйте графики**: Визуально анализируйте тренды
4. **Начните с малого**: Тестируйте на дешевых скинах
5. **Диверсифицируйте**: Не вкладывайте все в один предмет
